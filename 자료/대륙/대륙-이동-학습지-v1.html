대륙 이동 — 대륙은 움직이는 퍼즐 학습지

7장: 배운 것 한 장(아이용) · 직접 해보기 4장【지도용】 · 테스트 2장【측정용】 · 영상 「대륙 이동 — 2억 년 타임랩스」(2분)과 짝
아침 요약 — 대륙은 아주 천천히(1년에 몇 cm, 손톱 자라는 만큼) 움직인다. 2억 5천만 년 전에는 모든 대륙이 하나로 뭉친 판게아였고, 둘로 갈라진 뒤 흩어져 지금 지도가 되었다. 인도가 아시아에 부딪혀 히말라야가 솟았다. 영상을 한 번 보고 1장부터 한다. 준비물: 인쇄 7장(아이 수만큼), 가위, 풀, 연필, 빨강 색연필. 1장은 아이마다 한 장 더 있으면 좋다(오린 뒤에도 원본이 남게).
⚠️ 흔한 오해 둘: ① 대륙은 처음부터 지금 모양이었다 → 아주 천천히 움직여 왔고 지금도 움직인다. ② 옛날 지도는 사진이다 → 옛날일수록 과학자들이 추정한 그림이다(이 학습지의 옛 지도도 단순하게 그린 추정 그림).
【방법】 보아요 → "붙어 있어요, 떨어져 있어요?" → 옛날부터 차례로
① 지도에서 대륙이 붙었는지 떨어졌는지 말하기 ② 옛날 → 지금 차례로 놓기 ③ 모르면 힌트를 차례로: 그림 설명 읽어 주기 → 첫 글자 → 낱말 상자에서 같이 찾기
