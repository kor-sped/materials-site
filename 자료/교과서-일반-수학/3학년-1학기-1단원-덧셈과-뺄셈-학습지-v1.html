덧셈과 뺄셈 학습지 (단원 전체)

12장: 배운 것 한 장(아이용) · 직접 해보기 9장【지도용】 · 테스트 2장【측정용】 · 영상 「덧셈과 뺄셈」 v1과 짝
⚠️ 준비: 수 모형(백·십·일)이 있으면 ⑥~⑧에서 직접 풀어 보게 한다. 없으면 종이에 그린 막대·네모로 대신한다.
아침 요약 — 자리 맞추기·어림 → 덧셈(받아올림 없음 → 한 번 → 여러 번) → 뺄셈(받아내림 없음 → 한 번 → 두 번 → 0이 있는 수) → 생활 문제. 하루에 한두 장씩. 준비물: 인쇄 12장, 연필, 수 모형(선택).
【방법】 "일의 자리부터 봐요." · "위의 수가 작으면 어디서 빌려 와요?"
답을 바로 말하지 않고 힌트를 한 단계씩: 덧셈은 ① "같은 자리끼리" 손가락으로 짚기 → ② "10이 넘었어요?" → ③ 윗자리 작은 칸에 1. 뺄셈은 ① "위의 수가 작아요?" → ② "윗자리에서 10을 빌려 와요"(빗금, 하나 줄이기) → ③ 윗자리가 0이면 "한 자리 더 위". 계산 전에 어림(약 몇 백), 뺄셈 뒤에는 더해서 확인. 자리 칸의 색(일 초록 · 십 주황 · 백 파랑)은 영상과 같다.
