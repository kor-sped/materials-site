12장: 배운 것 한 장(아이용) · 직접 해보기 9장【지도용】 · 테스트 2장【측정용】 · 영상 「덧셈과 뺄셈」 v1과 짝
⚠️ 준비: 색연필 네 가지(파랑·주황·빨강·초록). ⑤·⑥장은 ○를 직접 그리는 장이라 시간을 넉넉히 둔다.
아침 요약 — 모으기 → 가르기 → 그림 보고 이야기 → 덧셈식 쓰고 읽기 → ○ 그려 더하기 · 빼기 → 짝 지어 비교 → 0 → 생활 문제 순서. 하루에 한두 장씩, ⑤·⑥장(그림 그려 덧뺄셈)에 시간을 더 쓴다. 준비물: 인쇄 12장, 색연필 네 가지, 바둑돌 10개(그리기가 힘들 때).
【방법】 "앞의 수만큼 ○를 그려요." · "빼는 수만큼 빗금을 그어요."
답을 바로 말하지 않고 힌트를 한 단계씩: ① "앞의 수만큼 ○를 그려요." → ② 더하기면 "더하는 수만큼 ○를 더 그려요.", 빼기면 "빼는 수만큼 빗금(/)을 그어요." → ③ "○를 세어 봐요."(빼기는 빗금 없는 ○만) → ④ 그래도 어려우면 바둑돌을 놓고 직접 옮긴다. 이어 세기·거꾸로 세기도 좋은 방법이다(시작 수는 세지 않고 다음 수부터).

배운 것

모으기 · 가르기 · 덧셈 · 뺄셈

오늘 배운 것 한 장
날짜 월 일이름

① 모으기 · 가르기

3과 4를 모으면 7.
7은 1과 6, 2와 5, 3과 4로 가를 수 있어요.

② ○ 그려 더하기   5 + 3

5개 그리고, 3개 더 그려요. 모두 세면 8.
읽기: 5 더하기 3은 8과 같습니다. / 5와 3의 합은 8입니다.

③ ○ 그려 빼기   8 − 3

8개 그리고, 3개에 빗금(/). 빗금 없는 ○는 5.
읽기: 8 빼기 3은 5와 같습니다. / 8과 3의 차는 5입니다.

④ 짝 지어 비교   6 − 4

하나씩 짝을 지으면 짝 없는 컵이 2개.
컵이 2개 더 많아요. 6 − 4 = 2
0 · 말 단서
0을 더하거나 빼면 그대로(5 + 0 = 5, 5 − 0 = 5). 같은 수를 빼면 0(5 − 5 = 0).
"모두 · 더 놓았다" → 덧셈 +  |  "남은 · 먹었다 · 더 많은" → 뺄셈 −  |  모르겠으면 ○를 그려요.
