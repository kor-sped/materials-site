배운 것

각기둥과 각뿔

오늘 배운 것 한 장
날짜 월 일이름

1. 각기둥

평행하고 합동인 두 다각형 = 밑면 (2개)
밑면과 만나는 면 = 옆면 (직사각형)
두 밑면 사이의 거리 = 높이

2. 각뿔

밑면 = 다각형 하나
옆면 = 삼각형, 한 점에 모여요
그 점 = 각뿔의 꼭짓점 → 밑면에 수직 = 높이

3. 이름은 밑면 모양으로

삼각형 → 삼각기둥 · 삼각뿔
사각형 → 사각기둥 · 사각뿔
오각형 → 오각기둥 · 오각뿔

4. 규칙 (밑면 변의 수 = )

면모서리꼭짓점
각기둥 + 2 × 3 × 2
각뿔 + 1 × 2 + 1

5. 각기둥의 전개도

모서리를 잘라 펼친 그림. 자른 모서리 = 실선, 접는 모서리 = 점선.
밑면 두 개는 옆면 띠의 서로 다른 쪽에 · 옆면 수 = 밑면 변의 수 · 만나는 모서리는 길이가 같게.
