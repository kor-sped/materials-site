12장: 배운 것 한 장(아이용) · 직접 해보기 9장【지도용】 · 테스트 2장【측정용】 · 영상 「길이 재기」 v1과 짝
⚠️ ⑤ ⑧ ⑨ 측정 2는 줄자가 있어야 한다. 짝마다 하나씩 미리 챙긴다. 줄자 끝이 0이 아닌 것이 있으니 먼저 살펴본다.
아침 요약 — 1m를 알고 길이를 두 가지로 말한다. 줄자로 진짜 물건을 재고, 내 몸으로 어림한다. 하루에 한두 장씩, ③(0 조심)과 ⑤(재기)에 시간을 더 쓴다. 준비물: 인쇄 12장, 짝마다 줄자, 연필.
【방법】 "100cm를 먼저 찾아요." · "m는 m끼리, cm는 cm끼리."
답을 바로 말하지 않고 힌트를 한 단계씩: ① "100cm는 몇 m예요?" → ② "100cm를 빼면 얼마가 남아요?" → ③ "m 칸과 cm 칸을 나눠 봐요." → ④ 그래도 어려우면 줄자에서 같이 짚는다. 몸 길이는 아이마다 다르다. 서로 견주지 않는다.

길이 재기

오늘 배운 것 한 장
날짜 월 일이름

① 1m

100cm = 1m
1m라고 쓰고, 일 미터라고 읽어요.
1cm가 백 번 들어가요.

② 두 가지로 말해요

130cm = 1m 30cm
100cm를 먼저 찾아요.
남은 것은 cm로 말해요.

③ 0 조심

1m 5cm = 105cm
150cm가 아니에요.
빈자리에 0을 써요.

④ 줄자로 재기

0을 찾아 맞춰요 → 곧게 펴요 → 끝의 눈금을 읽어요.

⑤ 줄자 눈금

끈이 눈금 130에 닿았어요. 130cm, 1m 30cm예요.

⑥ 더하기 · 빼기

m는 m끼리, cm는 cm끼리 계산해요.
1m 20cm + 1m 40cm = 2m 60cm

⑦ 어림

내 몸의 길이를 재어 두어요.
어림한 길이는 약을 붙여 말하고, 재어서 확인해요.
