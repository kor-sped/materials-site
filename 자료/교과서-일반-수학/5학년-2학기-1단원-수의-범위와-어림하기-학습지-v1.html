12장: 배운 것 한 장(아이용) · 직접 해보기 9장【지도용】 · 테스트 2장【측정용】 · 영상 「수의 범위와 어림하기」 v1과 짝
⚠️ 준비: 색연필 두 가지(파랑·주황) — 수직선에 ●·○를 그리고 칠할 때 쓴다. 해보기 ⑤는 바둑돌·공깃돌 30개쯤과 종이컵(10개씩 담기)이 있으면 좋다.
아침 요약 — 수의 범위(이상·이하 → 초과·미만 → 수직선 → 두 말 합치기) → 어림(올림 → 버림 → 반올림 → 소수 → 생활에서 고르기) 순서. 하루에 한두 장씩. 준비물: 인쇄 12장, 색연필 파랑·주황, 바둑돌 30개·종이컵(선택).
【방법】 "그 수도 들어가요? 빠져요?" · "어느 자리까지 남겨요? 바로 아래 숫자는?"
답을 바로 말하지 않고 힌트를 한 단계씩: 수의 범위는 ① "같아도 돼요?"(이상·이하 = 들어가요 ●) → ② "큰 쪽이에요, 작은 쪽이에요?"(오른쪽·왼쪽) → ③ 수직선에 그려 본다. 어림은 ① "어느 자리까지?" 손가락으로 짚기 → ② "바로 아래 숫자는?" → ③ 올림은 0이 아니면 올림, 버림은 늘 버림, 반올림은 숫자 띠를 본다. 생활 문제는 "남은 것을 두고 갈 수 있어요?"로 올림·버림을 고르게 하고, 까닭은 "왜냐하면 ~니까요".
