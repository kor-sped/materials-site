⚠️ 준비: 바둑돌이나 연결 모형 100개쯤(10개씩 묶음 9개 + 낱개). 달걀 판(10구)이 있으면 더 좋다. 배운 것 장 아래 세로셈 칸을 잘라 둔다.
아침 요약 — 몇십 + 몇 → 두 자리 수끼리 더하기 → 빼기 → 이어 세기 → 세로셈 → 이야기 · 식 → 생활 문제 → 숫자 카드 놀이 순서. 받아올림 · 받아내림은 없다. 하루에 한두 장씩, ②와 ④(낱개 먼저 → 묶음)에 시간을 더 쓴다. 준비물: 인쇄 12장, 바둑돌 100개, 색연필(파랑 · 주황 · 초록), 숫자 카드 0~9.
【방법】 "묶음은 묶음끼리, 낱개는 낱개끼리." · "낱개 먼저."
답을 바로 말하지 않고 힌트를 한 단계씩: ① "묶음이 몇 개, 낱개가 몇 개예요?" → ② "낱개끼리 먼저 해 볼까요?" → ③ "이제 묶음끼리 해요." → ④ "묶음 수를 앞에, 낱개 수를 뒤에 써요." → ⑤ 그래도 어려우면 바둑돌을 10개씩 줄 세워 직접 놓고 덜어 낸다. 어떤 방법(판 그림 · 이어 세기 · 세로셈)으로 했든 "어떻게 했는지" 말하게 한다.
