3. 변수 — 주 방법 우선순위 1

3.1 무엇이고 언제 쓰나

변수는 HTML 안에 "여기는 나중에 값이 들어온다"고 표시해 두고, 렌더할 때 값을 넣는 장치다. 같은 파일에서 다른 영상이 나온다. 읽는 길은 셋뿐이다.

길쓰는 법이 편에서
글자 바꾸기요소에 data-var-text="id" (안의 글이 대체값)(안 씀 — 요일 글자는 블록이 만듦)
파일 바꾸기<img>·<audio>에 data-var-src="id" (src가 대체값)목소리 조각 둘
계산해서 쓰기스크립트에서 getVariables()와 window.__hfVariables를 합쳐 한 번 읽기동그라미 자리, 글자판 글자, 내일(+1)

언제: 학생마다·날마다·문제마다 같은 틀에 값만 다른 영상. 요일(7), 시계 문제(100), 급식 메뉴, 이름 넣은 생일 축하. 학생 이름을 넣으면 배포 범위를 먼저 생각한다.

3.2 프롬프트

한 줄
요일 영상을 변수로 만들어 줘. 오늘 요일(day)만 바꾸면 달력 동그라미·글자판·"오늘은 ○요일이에요" 목소리가 같이 바뀌고, 7편을 한 번에 렌더하게.
자세히
video-04-요일/ 에서:
1. plan/ch04.json 에 variables 선언: day(enum 월~일, 기본 월), todayClip·tomorrowClip(string, 기본 assets/clips/today-월.wav 등).
2. 대본 6·7문단의 [쉼3] 자리에 clips 로 조각을 얹어(앵커 "오늘이에요." 끝, "옆이에요." 끝) <audio data-var-src>가 되게.
3. 달력(week)에 act "mark"(var day, offset 0)와 offset 1(내일, cls next)로 동그라미. 자리는 렌더 시작 때 getVariables()로.
4. split-flap-board 를 설치해 배경 투명·y 560·한글 자판으로 고치고, boardText 대신 vars.day 에서 "○요일"을 만들게. 내일용은 -next 복사본에 DAY_OFFSET=1.
5. tts/gen-clips.py 로 "오늘은 ○요일이에요"·"내일은 ○요일이에요" 14개 조각을 만들고, days.json(rows 7줄)으로 render --batch --strict-variables.

먼저 실험했다. 3초짜리 시험 프로젝트에서 대체값은 무음, 변수로 880Hz 음을 넣고 렌더 → ffmpeg volumedetect가 -21dB(소리 있음)를 잡았다. 문서의 "소리 추출은 원래 속성을 읽는다"는 문구는 대체값이 있어야 한다는 뜻이지, 변수가 무시된다는 뜻이 아니었다.

첫 일괄 렌더: 소리만 바뀌고 그림·글자판은 월요일서브 컴포지션의 getVariables()는 자기 변수만. 호스트 값은 window.__hfVariables둘을 합쳐 읽게(빌더·블록). 시험 프로젝트로 확인 후 재렌더(3.3 ③)

check 오류 6개 (글자 겹침)글자판의 반쪽 글자 구조data-layout-allow-overlap 표시(4장)

snapshot에 --variables 없음명령이 지원 안 함기본값으로 보고, 값 변화는 렌더 프레임(ffmpeg -ss)으로
--batch에 JSONL을 줌형식은 JSON 배열 또는 {rows:[…]}days.json으로 바꿈
"금요일"이 줄 끝에서 쪼개짐낱말 span이 inlineinline-block

용어집

변수 (variable)
HTML 밖에서 값을 넣어 같은 장면을 다르게 찍는 장치. 선언은 <html data-composition-variables>(배열), 값은 --variables 또는 값 목록(객체).
선언 · 값
선언 = 무엇이 바뀔 수 있나(id·type·label·default). 값 = 이번 렌더에 넣는 것. 둘의 JSON 모양이 다르다.
일괄 렌더 (render --batch)
값 목록의 줄마다 한 편씩 렌더. renders/manifest.json에 결과가 남는다.
data-var-src · data-var-text
요소의 파일 경로·글자를 변수로 바꾸는 표시. 원래 src·글자는 대체값.
getVariables() · window.__hfVariables
변수 값을 읽는 두 창구. getVariables()는 그 컴포지션 자기 변수, __hfVariables는 호스트(index.html)에 렌더 때 넣은 값. 서브 컴포지션에서는 둘을 합쳐 읽는다. 렌더 시작 때 한 번만.
드럼 (flap alphabet)
글자판이 도는 글자 순서. 이 순서로 한 칸씩 넘어가다 목표 글자에서 멈춘다.
조각 (clip)
변수로 바꿔 끼우는 짧은 목소리 파일. tts/gen-clips.py가 만든다.
