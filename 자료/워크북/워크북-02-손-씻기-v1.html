3. 카탈로그 블록 사용법 전체 — 주 방법 우선순위 1

3.1 무엇이고 언제 쓰나

카탈로그에는 블록과 컴포넌트가 374개 있다(2026-09-09 기준). 블록은 서브 컴포지션이라 "언제, 몇 초, 어느 층"만 정해 호스트에 얹으면 끝이다. 블록 안의 움직임은 블록 파일이 스스로 가지고 있다.

언제 쓰나: 우리 스케치 빌더로 그리기 번거로운 완성된 움직임이 필요할 때(손글씨 상자·전광판·말풍선·전환). 시계 바늘처럼 낱말마다 다르게 움직여야 하는 것은 블록보다 plan이 낫다 — 블록의 시간표는 블록 안에 고정돼 있기 때문이다(9장).

3.2 프롬프트

이 편을 만들 때 실제로 쓴 지시. 한 줄은 클로드가 알아서 찾게, 자세히는 결과를 정확히 정할 때.

한 줄 (명세 다이얼 낮게)
손 씻기 다섯 단계 영상에 카탈로그의 hw-pipeline 블록으로 물→비누→비비기→헹구기→수건 다섯 칸을 넣어 줘. 여는 말과 닫는 말에 한 번씩.
자세히 (명세 다이얼 높게 — 파일·값까지)

2. 설치된 compositions/hw-pipeline.html 의 CONFIG 를 고쳐: nodes 다섯(물·비누·비비기·헹구기·수건), boxW 280, gap 80, y 560(자막 위), fontSize 64.

3.3 파일에 쓰는 법 (6단계)

① 찾기 — 영어로 묻는다

카탈로그는 영어로만 검색된다. 한글로 물으면 "No searchable words"가 나온다. 움직임을 영어로 묘사하고, 화면 글자는 나중에 한글로.

video-02-손-씻기/ 에서
npx -y hyperframes@0.8.30 catalog --query "steps pipeline boxes arrows drawn in sequence"
실제로 나온 답(앞부분). Type이 block이면 파일 하나로 얹고, component면 내 장면 HTML에 붙여 넣는다
Name                        Type        Description
hw-pipeline                 block       Wobbled boxes with handwritten labels joined by curved connectors, drawing on in sequence from a node list [handwritten, diagram, data-viz, overlay]
hw-arrow                    component   Wobbled draw-on arrow …
hw-box-label                component   Wobbled rounded rectangle draws on …

이름을 이미 알면 npx hyperframes catalog로 표 전체를 보거나 --type block --tag handwritten으로 거른다.

② 설치 — add 한 줄

npx -y hyperframes@0.8.30 add hw-pipeline --no-clipboard
실제로 나온 답. 어디에 설치됐는지(hyperframes.json의 paths.blocks = compositions)와 얹는 조각을 알려 준다
✓ Added hw-pipeline (hyperframes:block)
  compositions/hw-pipeline.html
  assets/fonts/Caveat-700-latin.woff2

Include snippet:
  <div data-composition-src="compositions/hw-pipeline.html" data-duration="7" data-width="1920" data-height="1080"></div>

add는 인터넷이 필요하다(설치할 때마다 파일을 받는다). 검색은 오프라인도 된다.

③ 고치기 — 설치된 파일의 CONFIG

블록 파일을 열면 var CONFIG = { … } 상자가 있다. 여기가 "바꿔도 되는 값". 아래는 우리가 고친 뒤의 실제 내용.

compositions/hw-pipeline.html 의 CONFIG (고친 뒤)
        var CONFIG = {
          nodes: [{ label: "물" }, { label: "비누" }, { label: "비비기" }, { label: "헹구기" }, { label: "수건" }],
          boxW: 280, // 다섯 칸: 5×280 + 4×80 = 1720 (화면 1920 안)
          boxH: 150,
          gap: 80, // px between boxes
          y: 560, // top of the row; x centers automatically. 자막(아래 70px)과 겹치지 않는 높이
          fontSize: 64,
          seed: 11,
          boil: { enabled: true, amp: 1.6, rot: 0.4, frameDrop: 3 },
          animationOut: true,
        };
값뜻우리 값 · 이유
nodes상자 목록. label이 글자다섯 단계 이름
boxW · gap상자 너비, 사이 간격(px)280·80 → 5×280+4×80=1720, 화면 1920 안
y상자 줄의 윗변(px). 가로는 자동 가운데560 → 자막(아래 70px)과 안 겹침
fontSize글자 크기64(아이들용)
boil손그림 떨림. amp 세기, frameDrop 몇 프레임마다그대로
animationOut끝에 흐려져 사라짐true

글꼴·색은 CONFIG가 아니라 위쪽 <style>의 CSS 변수에 있다. 블록은 어두운 배경용(밝은 잉크)이 기본이라 종이 바탕엔 색을 뒤집어야 한다.

compositions/hw-pipeline.html 의 글꼴·색 (고친 줄만)
        font-family: "Apple SD Gothic Neo";
…
        src: local("Apple SD Gothic Neo");
…
        --hw-font-print: "Apple SD Gothic Neo", "Caveat", cursive;
…
        --hw-font-script: "Apple SD Gothic Neo", "Caveat", cursive;
…
        --hw-ink: #2B2B2B; /* 원래 #f4f2ec(어두운 배경용) → 종이 바탕이라 검정 */
…
        --hw-accent: #B5541A; /* 원래 #ffb020 → 우리 스케치 주황 */
…
        font-family: var(--hw-font-print, "Caveat", cursive);
…
        stroke: var(--hw-ink);
…
        stroke: var(--hw-accent);
…
        color: var(--hw-ink);
…
        text-shadow: none; /* 원래 그림자는 어두운 배경용 */
한글 글꼴 손글씨 블록의 Caveat 글꼴에는 한글이 없다. --hw-font-print에 "Apple SD Gothic Neo"를 앞에 두면 한글은 고딕, 영문·숫자는 Caveat로 나온다. @font-face … local() 선언이 없으면 check가 글꼴 경고를 낸다.

④ 잇기 — 호스트 index.html에 얹는 조각

블록은 호스트에 data-composition-src로 얹는다. 우리는 이 줄을 손으로 쓰지 않고 plan의 blocks에 적으면 빌더가 낱말 시각을 넣어 써 준다.

plan/ch02.json 의 blocks — at: 대본 낱말, para: 몇째 문단에서 찾나, dt: 초 보정, dur: 블록 길이, track: 층
{
  "blocks": [
    {
      "id": "hw-pipeline",
      "src": "compositions/hw-pipeline.html",
      "at": "손 씻기는",
      "para": 1,
      "dt": -0.2,
      "dur": 7,
      "track": 3
    },
    {
      "id": "hw-pipeline-end",
      "src": "compositions/hw-pipeline-end.html",
      "at": "손 씻기 다섯",
      "para": 11,
      "dt": -0.3,
      "dur": 7,
      "track": 3
    }
  ]
}
빌더가 index.html 에 써 준 줄 (data-start 가 낱말 시각 4.03·119.14)
  <div id="blk-hw-pipeline" data-composition-id="hw-pipeline" data-composition-src="compositions/hw-pipeline.html" data-start="4.03" data-duration="7.00" data-track-index="3" data-width="1920" data-height="1080"></div>
…
  <div id="blk-hw-pipeline-end" data-composition-id="hw-pipeline-end" data-composition-src="compositions/hw-pipeline-end.html" data-start="119.14" data-duration="7.00" data-track-index="3" data-width="1920" data-height="1080"></div>
속성뜻주의
data-composition-id블록 안의 id와 똑같아야다르면 렌더가 45초 기다리다 정지 화면
data-start · duration시작 초 · 길이길이는 블록 자체 길이(7) 이하
data-track-index층. 클수록 앞장면 1, 나레이션 2, 블록 3

⑤ 자리·크기 — 블록은 화면 전체(1920×1080)를 덮는 투명한 층

블록 안의 y=560이 화면의 y=560이다. 우리 장면의 그림 영역은 화면 (110,170)부터 1700×640이므로, 여는 말 장면의 선생님·말풍선은 y 340 위에 두어 블록과 겹치지 않게 했다. 블록을 화면 일부에만 넣으려면 얹는 div에 style="position:absolute; right:0; top:0; width:40%"처럼 준다.

⑥ 같은 블록을 두 번 쓰기 — 복사하고 id를 바꾼다

같은 id의 블록을 두 번 얹으면 시간표 이름이 겹친다. 파일을 복사해 세 곳의 이름을 바꾼다.

복사 + 이름 바꾸기 (우리는 파이썬으로 했지만 이 두 줄과 같다)

7. 새 손 그림을 그림 원소로 넣기 — 그림 재료 참고

수도꼭지·비누·두 손·헹구기·수건은 아이들 그림이 아니라 lib/sketch.mjs의 PRIM에 선 그림으로 새로 만들었다. 이름은 faucet·hand·hands·soap·rinse·towel. 선(class="ink")은 나타날 때 그려지듯 그어지고, 종이(paper)는 뒤에 채워진다.

lib/sketch.mjs 의 faucet — x,y 기준으로 관·손잡이·물줄기·세면대를 경로 하나씩
  faucet({ x, y, s = 1, id }) {
    const t = (px, py) => `${R(x + px * s)} ${R(y + py * s)}`;
    const pipe = `M${t(60, 20)} L${t(60, 110)} M${t(60, 20)} L${t(150, 20)} Q${t(200, 20)} ${t(200, 60)} L${t(200, 95)} M${t(30, 8)} L${t(90, 8)} M${t(60, 8)} L${t(60, 20)}`;
    const basin = `M${t(-40, 250)} Q${t(120, 330)} ${t(300, 250)}`;
    const wave = (px) => `M${t(px, 100)} q${R(-8 * s)} ${R(25 * s)} 0 ${R(50 * s)} t0 ${R(50 * s)}`;
    return `<g id="${id}"><path class="ink" d="${pipe}"/><path class="ink thin" d="${basin}"/><path id="${id}-w" class="ink thin" d="${wave(186)} ${wave(200)} ${wave(214)}"/></g>`;
  },

새 원소를 더하려면: ① PRIM에 함수 하나 추가(반드시 <g id="…">로 감싸고 선은 ink, 면은 paper) ② plan의 scene에 {"k":"이름", …} ③ 빌더는 ink를 drawOn으로 그린다. 아이들이 그린 그림을 쓰려면 03편(새 그림 → 캐릭터 변환)에서.

용어집

카탈로그 (catalog)
하이퍼프레임이 나눠 주는 재사용 부품 저장소. 블록·컴포넌트 374개. npx hyperframes catalog로 보고 add로 설치.
블록 (block)
장면 하나짜리 완성 HTML. 크기·길이·움직임을 스스로 가진다. 호스트에 data-composition-src로 얹는다.
컴포넌트 (component)
효과 조각. 크기·시간이 없어 내 장면 HTML 안에 HTML·CSS·JS를 붙여 넣는다.
서브 컴포지션 (sub-composition)
따로 된 HTML 파일을 호스트가 시간 맞춰 끼워 넣는 것. 우리 장면 ch02.html도, 카탈로그 블록도 서브 컴포지션이다.
호스트 (index.html)
영상 전체를 정하는 파일. 층(트랙)마다 장면·소리·블록을 언제부터 몇 초 보일지 적는다. 빌더가 만든다.
PRIM
lib/sketch.mjs의 그림 원소 함수 목록(teacher·bubble·door·faucet…). plan의 scene에서 k=이름으로 부른다.
앵커 (at)
그림·글·동작이 나타날 대본 낱말. 시각은 전사에서 가져온다.
트랙 (data-track-index)
호스트의 층. 같은 트랙에서 시간이 겹치면 오류. 숫자가 클수록 앞에 보인다.
check
npm run check. 렌더 전에 문법·겹침·글꼴·대비를 검사한다. 0 error가 렌더 조건.
