불을 끄는 소방차

1소방차는 불이 난 곳으로 달려가요. 소방차는 큰 소리를 내며 달려요. 소방차 소리를 들으면 다른 차들은 길을 비켜 줘요.

2소방차는 큰 통에 물을 싣고 다녀요. 소방관은 소방차의 긴 호스로 불을 꺼요. 사다리가 달린 소방차는 높은 곳까지 올라가요.

영상이 멈추면① 혼자 읽어요 → ② 여러 번 나오는 낱말에 ○ 해요 → ③ 문단 끝 신호등에 색칠해요(초록 알았어요 · 노랑 다시 읽어요 · 빨강 물어봐요)

「문단 읽기」 두 문단 ⑦ 불을 끄는 소방차

영상(5~6분)과 짝 · 영상이 스스로 멈추는 시간에 아이가 글 장 · 활동 장을 채워요
아침 요약 — 영상을 틀고, 막대가 줄어드는 동안 아이와 함께 해요. 시간이 모자라면 영상을 잠깐 멈추세요. 아이 답은 아이가 쓰고, 막히면 아래 힌트를 차례로 말해요.
  1. 준비물: 글 장 · 활동 장(아이 수만큼) · 연필 · 색연필 두 가지(낱말 ○ · 신호등 색칠)
  2. 영상 순서: 제목 보고 묻는 말(멈춤 20초) → 문단마다 혼자 읽기 → 같이 읽기 → 여러 번 나오는 낱말(15초) → 한 줄로(7초) → 신호등(5초) → 무엇에 대한 글 → 묻는 말 답 찾기
  3. 쓰기가 힘들면 짚기 · 말하기로 답해도 돼요. 선생님이 받아 적어 주세요.
번호정답답이 있는 곳힌트 2단계 → 3단계 (교사 말)
1(아이가 만든 말) 본보기: 소방차는 어디로 달려가요? · 소방관은 무엇으로 불을 꺼요?—“제목에서 궁금한 낱말이 뭐예요?” → “소방차는 … ? 앞을 이어 말해 봐요.”
2첫째 문단: 소방차 3번, 소리 2번
둘째 문단: 소방차 3번		문단마다 셈“제목을 봐요.” → “제목 낱말이 문단에 또 있어요? 손으로 짚으며 함께 세요.”
3첫째: 소방차가 달려가는
둘째: 소방차로 불을 끄는		문단마다 같은 이야기“이 문단에서 소방차가 무엇을 해요?” → “달려가는 이야기예요, 불을 끄는 이야기예요?”
4소방차제목 + 가장 많이 나온 낱말“2번에서 센 낱말을 봐요.” → “제목과 같은 낱말이 있어요?”
5 (어디)불이 난 곳첫째 문단 첫째 문장“몇째 문단에 있을까요?” → “그 문단을 다시 읽어요. 같이 짚어요.”
5 (무엇)긴 호스둘째 문단 둘째 문장“몇째 문단에 있을까요?” → “그 문단을 다시 읽어요. 같이 짚어요.”
5 (무엇)글에 없어요두 문단 어디에도 없음“두 문단을 끝까지 짚어 봐요.” → “없으면 지어내지 않고 ‘글에 없어요’라고 말해요.”
신호등 낱말 — ‘호스’ = 물이 지나가는 길고 말랑한 관. 노랑이면 다음 문장까지 다시 읽고, 그래도 모르면 빨강(물어봐요). 잘 걸리는 곳 — 제목 첫 낱말 ‘불’을 중심 낱말로 고름 — ‘불’은 글에 두 번, ‘소방차’는 여섯 번이고 제목에도 있어요. ‘소방관’은 ‘소방차’와 다른 낱말이라 세지 않아요.
